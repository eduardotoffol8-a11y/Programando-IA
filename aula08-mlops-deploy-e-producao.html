📉 Missão 1 — Quantização de Modelos: Cortando a Conta da GPU pela Metade +35 XP

Modelos modernos como LLaMA-3 ou Mistral possuem bilhões de parâmetros. Se cada peso for armazenado em 32 bits (FP32), o modelo exige centenas de gigabytes de memória de vídeo (VRAM) e servidores que custam milhares de dólares por mês.

⚡ Missão 2 — Construindo a API de Produção com FastAPI +40 XP

Em produção, softwares da empresa (web, mobile, ERP) conversam com a IA via API RESTful. O padrão da indústria em Python é o FastAPI com validação estrita via Pydantic.
Inspecione as 3 partes do código abaixo clicando nelas e depois faça uma requisição de teste:

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field
app = FastAPI(title="Classificador de Sentimentos API")
# Contrato de Entrada (Evita que o usuário envie dados inválidos)
class AnaliseRequest(BaseModel):
    texto: str = Field(min_length=5, max_length=500)
    temperatura: float = Field(default=0.2, ge=0.0, le=1.0)
# Endpoint HTTP POST
@app.post("/v1/analisar")
async def analisar_sentimento(payload: AnaliseRequest):
    resultado = modelo.predict(payload.texto)
    return {"sentimento": resultado, "status": "ok"}

🚨 Missão 3 — O Assassino Silencioso: Data Drift & Concept Drift +40 XP

Um modelo de Machine Learning não se desgasta fisicamente, mas ele apodrece com o tempo porque os hábitos das pessoas e as regras de mercado mudam. Existem dois tipos:

  • Data Drift: Os dados de entrada mudaram de formato ou escala (ex: nova gíria nas redes, inflação mudando a faixa de preços).
  • Concept Drift: A relação entre as variáveis mudou (ex: antes da pandemia, comprar 50 máscaras indicava um hospital; durante a pandemia, qualquer pessoa comprava).

No Mês 1 o modelo acabou de ser treinado com dados recentes. Desempenho máximo!
