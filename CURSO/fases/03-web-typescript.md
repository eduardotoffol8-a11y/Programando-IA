# Fase 03 — Frontend web e TypeScript

**Semanas:** 19–26 · **Carga estimada:** 96 horas. Avance por domínio real, não automaticamente por data.

## Por que esta fase existe
Entender interface como software: estados, acessibilidade, contratos, assíncrono e manipulação confiável de entradas.

## Conhecimentos a dominar
HTML semântico, CSS responsivo, acessibilidade, DOM, JS, eventos, arrays/objects, modules, async/await, fetch, TypeScript, tipos/union, estado UI, validação, componentes, web performance, browser devtools, testes frontend.

## Projeto de aplicação
Frontend OficinaOS com dados fictícios, estados úteis e testes.

## Gate obrigatório para prosseguir
Explicar event loop em nível introdutório, API fetch, estado e TypeScript; demonstrar fluxo acessível sem IA.

## Inglês no trabalho
component, state, async, request, response, loading, error state, accessibility.
