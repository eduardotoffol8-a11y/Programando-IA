# Fase 01 — Programação Python e algoritmos fundamentais

**Semanas:** 3–10 · **Carga estimada:** 96 horas. Avance por domínio real, não automaticamente por data.

## Por que esta fase existe
Expressar regras em código simples sem perder o entendimento da ciência da computação.

## Conhecimentos a dominar
Python syntax como notação, tipos, variáveis, operações, bool, strings, if/elif, laços, funções, escopo, parâmetros, retorno, decomposição, módulos, erro/exceção, arquivos, JSON, pytest, debugging.

## Projeto de aplicação
CorteJusto v1, motor de cálculo, com entradas sintéticas e contrato explícito.

## Gate obrigatório para prosseguir
Desenvolver pequena função N0/N1, explicar fluxo, diagnosticar bug e passar na suíte de testes incluindo entradas inválidas.

## Inglês no trabalho
function, argument, return value, exception, loop, assertion, test failure; relatório de bug em inglês.
