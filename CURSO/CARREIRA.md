# Da aprendizagem às candidaturas

## Vagas-alvo iniciais (títulos variam)
- Junior Software Engineer / Software Developer
- Junior Backend Developer (Python)
- Junior Full Stack Developer
- Junior AI Application Engineer / Junior AI Engineer
- Junior AI Automation / Agent Engineer

Evitar reduzir a meta a "prompt engineer": candidatos fortes mostram engenharia verificável.

## Portfólio que interessa a uma equipe
Três repositórios destacados, cada um com:
1. Problema, usuário e objetivo comercial.
2. Arquitetura com justificativas e diagrama simples.
3. Setup reproduzível e demo segura.
4. Testes automáticos e evidências de qualidade.
5. Segurança e limitações reais.
6. Issues e PRs mostrando evolução e revisões.
7. README e demonstração resumida em inglês.

## Preparação para trabalhar
- Prática de leitura de documentação e codebase desconhecida.
- Resolução de problemas de estruturas de dados de nível inicial.
- SQL, HTTP, operações de API e debugging.
- Pair programming e code review; revisão de contribuições abertas quando possível.
- Entrevista comportamental usando situações verdadeiras dos projetos.
- System design simples: requisitos, dados, limites, falhas, custo.
- Comunicação assíncrona e verbal em inglês; noções de cultura de time.
- Currículo e perfil profissional refletindo evidências verificadas, sem alegar experiência que não teve.

## Portas de candidatura
**Gate A:** consegue resolver tarefas pequenas sem ajuda, revisar PR e explicar arquitetura.
**Gate B:** mantém aplicação full stack com testes, deploy, logs e rollback.
**Gate C:** sistema de IA com evals, segurança e métrica de custo/latência.
Com A/B, buscar estágios, colaboração e junior software roles; com C, ampliar para AI application roles. Cargos são variáveis e a seleção pode exigir formação/experiência adicional.

## Indicadores mensais
Competências rubricadas, issues finalizadas com critério, bugs corrigidos, PRs revisados, demos em inglês, entrevistas simuladas, lacunas identificadas. Não confundir atividade com domínio.
