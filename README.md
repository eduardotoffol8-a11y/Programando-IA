## A proposta
Uma empresa-escola: cada desafio tem um cliente simulado, requisitos, restrições, entregáveis, critérios de aceite, revisão e retrospectiva. A progressão depende da demonstração de competência, não apenas de assistir às aulas ou de copiar respostas de IA.

- **Público:** iniciante absoluto que deseja trabalhar como Software Engineer, Full Stack Engineer ou AI Application Engineer.
- **Meta:** autonomia para raciocinar, ler/escrever/manter software, colaborar por Git, usar IA com responsabilidade e candidatar-se a vagas iniciais no Brasil e exterior.
- **Estimativa, não promessa:** 72 semanas em ritmo de ~12 h/semana (~864 h). Mais ou menos conforme desempenho, disponibilidade e experiências anteriores.
- **Linguagens:** Python primeiro para clareza e backend/IA; SQL; JavaScript e TypeScript para web. Ferramentas mudam; fundamentos permanecem.
- **Comprovação:** GitHub com histórico de commits, issues, PRs, testes, documentação, demonstrações e decisões técnicas.
- **Inglês:** leitura, explicação oral/escrita, code reviews, reuniões e entrevistas integrados às tarefas.
- **IA:** parceira de trabalho e crítica, nunca substituta da compreensão.

## Padrão de entrega
Issue com problema → análise de requisitos → plano → implementação incremental → testes → PR → explicação em inglês → feedback → retrospectiva. Evidência verificável antes do selo de conclusão.

## Princípio de carreira
O currículo se orienta por responsabilidades verificáveis de anúncios de AI Engineer / Software Engineer, não por promessas de contratação. A vaga final depende também de comunicação, experiência, entrevistas, idioma e mercado. A tecnologia do curso deve ser revista periodicamente.
