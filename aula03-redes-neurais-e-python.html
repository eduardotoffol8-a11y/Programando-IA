🐍 Missão 3 — Traduzindo para Python (Interativo!) +35 XP

Programar IA em Python é mais simples do que parece. Clique em cada linha de código abaixo para traduzir para português claro:

# 1. Dados de entrada e pesos
entradas = [1.0, 0.0, 1.0] # sol, carro, dinheiro
pesos = [2.0, 1.0, 0.5] # importância de cada um
vies = -2.0 # tendência inicial (bias)
 
# 2. Soma ponderada do neurônio
soma = (entradas[0]*pesos[0] + entradas[1]*pesos[1] + entradas[2]*pesos[2]) + vies
 
# 3. Função de Ativação (ReLU)
saida = max(0, soma)
print("Resultado do neurônio:", saida)

💻 Missão 4 — Simulador Python: Complete o Código e Rode! +35 XP

Chegou a hora de você programar o ajuste de peso do treinamento. Escolha o sinal correto na fórmula de aprendizado e clique em Rodar Python:

peso = 0.2
taxa_aprendizado = 0.1
entrada = 2.0
resposta_certa = 10.0

for epoca in range(1, 16):
    previsao = entrada * peso
    erro = resposta_certa - previsao
    peso = peso (taxa_aprendizado * erro * entrada)
    print(epoca, previsao)
